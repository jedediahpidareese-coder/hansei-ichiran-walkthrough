44  The peerage decree （華族令）

imperial rescript / decree (詔勅), promulgated in the official gazette (官報) · 明治十七年七月七日（詔勅の日付）／七月八日（官報掲載） / July 7, 1884 (decree); gazetted July 8, 1884

This is the imperial rescript (詔勅) that created the modern Japanese peerage — the Five Ranks 公侯伯子男 — printed as the headline item under the masthead of the official gazette. In eight short clauses it demonstrates almost every hallmark of the Meiji imperial-rescript register at once: the Emperor’s self-reference 朕, katakana okurigana on classical verbs (惟フ, 示スヘシ), the 漢文訓読 auxiliaries なり / べし, a causative しむ, and pre-1946 old-kanji forms (國, 榮, 禮, 勞). Pairing the decree with one line of the ennoblement roster (授伯爵　從五位　伊達 宗基) also teaches the gazette’s terse column layout, where a person’s entire status change is compressed into “verb + court rank + name.” It is an ideal worked example because it is authoritative, self-contained, and every feature is representative rather than idiosyncratic.

Uncertain readings in this passage

  • 盆々 (clause 7): the source file transcribes 盆々, but on sense (‘ever increase your loyalty’) and standard rescript diction this is almost certainly 益々 (ますます). It is preserved verbatim in the genbun as 盆々 and read as ますます; the discrepancy (glyph or OCR confusion 益→盆) is not resolved against the page image here.
  • 勳冑 (clause 2): the source transcription file prints the second character as 冑 (U+5191, ‘helmet’). The compound sense ‘meritorious lineages/descendants’ properly belongs to the near-identical glyph 胄 (U+80C4, ‘lineage/heir’). The genbun preserves the source glyph 冑 verbatim; the reading くんちゅう and the gloss ‘lineages’ are unaffected, but whether the printed gazette glyph is 冑 or 胄 is not resolved against the page image here. This is a well-known 冑/胄 print conflation.
  • 秩ス reading: given as ちつす per サ変 秩す (on’yomi ちつ). The draft’s earlier ‘ちっす’ (sokuon contraction) was corrected to ちつす for consistency with the kakikudashi 秩(ちつ)す and the vocabulary reading; the exact printed okurigana beyond ス is not separately verifiable from the transcription file (the file gives only ス).
  • 爾 is listed among the 旧字体→新字体 pairs, but it is not strictly a simplified-form pair — it is an archaic second-person pronoun glossed as =汝 (なんじ). Retained for the reader’s benefit with that caveat.
  • The source file’s own audit (2026-05-26) flags that the merit-track wording 依父勳功特授 once claimed for the Sendai-Date entry was RETRACTED; the correct roster reading is 授伯爵　從五位　伊達 宗基 (lineage-track). This chapter uses the corrected reading, but the retraction is noted so the reader does not import the discredited 依父勳功 version.
  • The decree text is transcribed continuously without punctuation in the source (as printed); the clause boundaries in this chapter are editorial segmentation for teaching, not marks present in the genbun. The ‘…’ shown in the .qmd quotation (which truncates before 卿等盆々…) is likewise editorial and is NOT part of the genbun; the full source line 52 continues through 濟サシメヨ, which this chapter reproduces in clauses 7–8.
